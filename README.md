## Teste Automatizado da NF-e avaliação QA 

## Tecnologia
- Playwright
- TypeScript

## Execução

- Instalar dependências no cmd

- npm install

- Executar teste:

  npx playwright test --headed

## Cenário validado
- Login no sistema
- Cadastro de uma nova NF-e
- Seleção de natureza de operação
- Inclusão de destinatário
- Inclusão de produto
- Transmissão da NF-e
- Geração do DANFE
- Conferencia do produto com a Grade
